# Guest Post Management System

A web-based Guest Post Management System developed using:

- Frontend: HTML, CSS, JavaScript
- Backend: Flask (Python)
- Database: PostgreSQL

## Features

- Client Management
- Order Management
- Payment Management
- Search Functionality
- Dashboard with Total Clients, Orders, Payments and Revenue

## Project Structure

Frontend:
- index.html
- style.css
- script.js

Backend:
- app.py
- database.py
